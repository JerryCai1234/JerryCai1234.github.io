Sedentary Squat Counter Reminder ★

Published August 22, 2026

Status Complete
Tools C#, WPF (.NET Framework), Visual Studio
Category Mechatronics

Overview

To perpetuate the salubrious tenets of my last project, I wanted to find a solution to another friction point in my life that was adversely affecting my health. Like many people, I sit at my desk to do most of my studying and personal avocations. However, during long sedentary bouts of inactivity, I've physically noticed myself feeling stiff and lethargic. It turns out my anecdotal experiences are indeed valid and backed by extensive scientific research. Studies link prolonged sedentary behavior to higher risks of obesity, type 2 diabetes, heart disease, certain cancers, and early death; combined with the fact that approximately 31% of the world's adult population is at risk of incurring these hypokinetic diseases, I resolved that this was a problem worth pursuing.

The most effective resolution to counteract these diseases is to incorporate periodic active habits during prolonged inactive stints. The consensus that taking a walk is the "default" exercise actually overshadows the plethora of benefits of substituting in bodyweight squats. Due to its inherent biomechanical profile, it recruits large muscle groups such as the quads and glutes that act as glucose sponges during contraction; this results in lowering blood pressure and sending blood from the lower body to the head, improving overall executive function. Additionally, it is more accessible than walking as it doesn't take much room and can be done in less time.

Schematic

I decided to utilize the 3D tracking capabilities of the old Kinect sensor from my Xbox 360, paired with Kinect's own software infrastructure for Windows. Using the SkeletonBasics-WPF application from the Developer Toolkit in Visual Studio, this prototype was able to track my joints and process information.

Logic

The application periodically (adjustable time periods) pops up SkeletonBasics-WPF's interface with a rep counter that increments after each successive squat. The window can only be shut off after the repetitions hit the goal (also adjustable), giving a dire incentive for the user to actually complete the physical break. Custom detection logic also prevents cheating, in case a user wants to circumvent the system; each successive repetition is based on joint angle, barring half-reps, etc.

Challenges

A technical issue I ran into during testing was the repetition counter resetting back to zero after calibration. In SquatCounter, I added a one-liner of code to resolve this hiccup in the Reset() method: if (Reps >= Goal) { Reps = 0; }. This ensures that the program resets the rep counter only if the goal has been reached, meaning that the squats already done do not get wiped.

              this.sensor = potentialSensor;

            catch (IOException)
            {

            }

          {
            this.statusBarText.Text = Properties.Resources.NoKinectReady;
          }

          this.checkInTimer = new DispatcherTimer();
          this.checkInTimer.Interval = CheckInInterval;
          this.checkInTimer.Tick += (s, args) => this.StartCheckIn();
          this.checkInTimer.Start();
          this.Hide();
          this.ShowInTaskbar = false;
        }

        private void StartCheckIn()
        {
          this.squatCounter.Reset();
          this.isLocked = true;
          this.Dispatcher.Invoke(() =>
          {
            this.WindowStyle = WindowStyle.None;
            this.WindowState = WindowState.Maximized;
            this.Topmost = true;
            this.ShowInTaskbar = true;
            this.Show();
            this.Activate();
          });
        }

        private void EndCheckIn()
        {
          this.isLocked = false;
          this.Topmost = false;
          this.WindowState = WindowState.Normal;
          this.Hide();
          this.ShowInTaskbar = false;
        }

        private void WindowClosing(object sender, System.ComponentModel.CancelEventArgs e)
        {
          if (this.isLocked)
          {
            e.Cancel = true;
            return;
          }
          if (null != this.sensor) this.sensor.Stop();
          if (this.trayIcon != null) this.trayIcon.Visible = false;
        }

        private void SensorSkeletonFrameReady(object sender, SkeletonFrameReadyEventArgs e)
        {
          Skeleton[] skeletons = new Skeleton[0];
          using (SkeletonFrame skeletonFrame = e.OpenSkeletonFrame())
          {
            if (skeletonFrame != null)
            {
              skeletons = new Skeleton[skeletonFrame.SkeletonArrayLength];
              skeletonFrame.CopySkeletonDataTo(skeletons);
            }
          }

          Skeleton trackedSkeleton = null;
          foreach (Skeleton skeleton in skeletons)
          {
            if (skeleton.TrackingState == SkeletonTrackingState.Tracked)
            {
              trackedSkeleton = skeleton;
              break;
            }
          }

          if (trackedSkeleton != null)
          {
            if (!this.squatCounter.IsCalibrated)
              this.squatCounter.Calibrate(trackedSkeleton);
            else
              this.squatCounter.Process(trackedSkeleton);

            this.RepCountText.Text = this.squatCounter.IsCalibrated
              ? $"Reps: {this.squatCounter.Reps} / {this.squatCounter.Goal}"
              : "Stand still to calibrate...";

            if (this.isLocked && this.squatCounter.Reps >= this.squatCounter.Goal)
              this.EndCheckIn();
          }
        }
      }
      }
// SquatCounter.cs
    using Microsoft.Kinect;

    public class SquatCounter
    {
      private enum State { Up, Down }
      private State state = State.Up;
      private float standingKneeAngle;
      private int calibrationFrames = 0;
      private float angleSum = 0f;

      public bool IsCalibrated { get; private set; } = false;
      public int Reps { get; private set; } = 0;
      public int Goal { get; set; } = 20;

      private const float DownOffset = 60f;
      private const float UpOffset = 20f;
      private const int DebounceFrames = 8;
      private int framesPastDownThreshold = 0;
      private int framesPastUpThreshold = 0;

      private float GetKneeAngle(Skeleton skeleton)
      {
        var hip = skeleton.Joints[JointType.HipLeft].Position;
        var knee = skeleton.Joints[JointType.KneeLeft].Position;
        var ankle = skeleton.Joints[JointType.AnkleLeft].Position;
        float v1x = hip.X - knee.X, v1y = hip.Y - knee.Y, v1z = hip.Z - knee.Z;
        float v2x = ankle.X - knee.X, v2y = ankle.Y - knee.Y, v2z = ankle.Z - knee.Z;
        float dot = v1x * v2x + v1y * v2y + v1z * v2z;
        float mag1 = (float)System.Math.Sqrt(v1x * v1x + v1y * v1y + v1z * v1z);
        float mag2 = (float)System.Math.Sqrt(v2x * v2x + v2y * v2y + v2z * v2z);
        if (mag1 == 0 || mag2 == 0) return standingKneeAngle;
        float dotNorm = dot / (mag1 * mag2);
        if (dotNorm > 1f) dotNorm = 1f;
        if (dotNorm < -1f) dotNorm = -1f;
        return (float)(System.Math.Acos(dotNorm) * (180.0 / System.Math.PI));
      }

      public void Calibrate(Skeleton skeleton)
      {
        angleSum += GetKneeAngle(skeleton);
        calibrationFrames++;
        if (calibrationFrames >= 90)
        {
          standingKneeAngle = angleSum / calibrationFrames;
          IsCalibrated = true;
        }
      }

      public void Process(Skeleton skeleton)
      {
        if (!IsCalibrated) return;
        float dropFromStanding = standingKneeAngle - GetKneeAngle(skeleton);
        if (state == State.Up)
        {
          framesPastDownThreshold = (dropFromStanding > DownOffset) ? framesPastDownThreshold + 1 : 0;
          if (framesPastDownThreshold >= DebounceFrames)
          {
            state = State.Down;
            framesPastDownThreshold = 0;
            framesPastUpThreshold = 0;
          }
        }
        else
        {
          framesPastUpThreshold = (dropFromStanding < UpOffset) ? framesPastUpThreshold + 1 : 0;
          if (framesPastUpThreshold >= DebounceFrames)
          {
            state = State.Up;
            framesPastUpThreshold = 0;
            framesPastDownThreshold = 0;
            Reps++;
          }
        }
      }

      public void Reset()
      {
        if (Reps >= Goal) Reps = 0;
        IsCalibrated = false;
        calibrationFrames = 0;
        angleSum = 0f;
        state = State.Up;
        framesPastDownThreshold = 0;
        framesPastUpThreshold = 0;
      }
    }

Next Steps

Overall, I think this project was fairly practical in terms of resolving an actual health issue by prompting a real impetus to the user by periodically pausing their current screen with an inescapable interface until the squat goal has been hit. Moving forward, further iterations could incorporate an emergency opt-out button in the application interface, in case urgent work needs to resume. However, this recourse could be misused as a form of procrastination; if this system were to be implemented, accountability in the form of payment (each button donates money from a linked credit card, etc.) could be considered as a way to combat this. Another planned step to take is to further study joint-angle calculation via the dot product method in 3D Euclidean space, as the knee-angle detection math was outsourced. Some pre-studying will be set in motion to prepare for first year statics and dynamics which covers this topic.
